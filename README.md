# Turbo EverDrive PRO Themes

Menu themes for the [Turbo EverDrive PRO](https://krikzz.com/our-products/cartridges/turbo-everdrive-pro.html), styled after every console in the PC Engine family.

## Install

1. Copy the `.bgr` file(s) to `edturbo\themes` on the Turbo EverDrive PRO's microSD card.
2. On the console, press SELECT, choose **System Folder**, open `themes`, highlight a theme, press I and choose **Set Theme**.

Each theme comes in two layouts: full and slim. Additionally, every theme has a CRT version with bigger empty margins to account for overscan.
